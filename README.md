
# AnimalCare 🐾

AnimalCare is a modern, responsive web application designed to promote animal welfare and support rescue, treatment, and adoption initiatives. The website provides an engaging platform to spread awareness, showcase rescue efforts, and connect people with meaningful animal care activities.

# 🌟 Features

* **Rescue & Treatment Information**
  Highlights the organization’s efforts in rescuing injured and abandoned animals and providing medical care and rehabilitation.

* **Interactive Camps & Events Section**
  Displays upcoming events such as vaccination drives, adoption campaigns, and awareness programs with detailed pages for each.

* **Adoption Drive Pages**
  Dedicated pages with event details including date, time, location, descriptions, chief guests, and image galleries.

* **Rescue Stories (Cinematic UI)**
  Showcases real-life rescue stories with a premium, dark-themed design including before-and-after transformations.

* **Statistics Section**
  Displays impactful data such as number of animals rescued, treated, and adopted.

* **Contact Section**
  Allows users to connect, volunteer, or reach out for support.

## 💻 Tech Stack

* HTML5
* CSS3 (Modern UI & animations)
* JavaScript (Interactive components)
* Font Awesome (Icons)

## 🎯 Purpose

This project aims to:

* Spread awareness about animal welfare
* Encourage adoption over buying pets
* Provide information about rescue and treatment efforts
* Create a visually appealing and user-friendly experience
